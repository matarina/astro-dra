## 实现

- **富文本格式**：Europe PMC HTML、PubMed摘要XML及PMC正文XML保留上标/下标角色。未标明用途的上标保留为`[superscript:3]`；XML明确标注的文内参考标记保留为`[article-ref:3]`。不把它直接粘到技术名后，也不一律删除数字。数学指数、离子电荷、下标和普通文本中的prime字符仍保留。已有纯文本缓存没有格式信息，无法反推原始标签。
- **同篇身份**：显式DOI/PMID/PMCID与规范论文入口的URL标识共用解析方法；支持DOI、PubMed、PMC、Europe PMC、Nature和部分Springer/BMC论文入口。Collector在搜索与fetch注册时复用已知来源；publication补齐共享标识，兼容池中已有不同入口的编号，再沿用现有展示编号整理。没有按标题相似度强行归并，也不从正文参考书目采集DOI。相互冲突的显式标识不作为归并依据。不是对所有出版商和缺标识来源的完整消重。
- **正式勘误关系**：两搜索适配器保留服务返回的CommentsCorrections关系，合并来源时保留这些关系；Agent片段显示关系，citation handler把已关联的勘误元数据/可用文字附到原论文材料块。即便勘误没有独立入选，保留的原论文仍携带该关系。通知与论文正文明确分开；只有元数据时不声称知道改了什么，没有新增网络抓取或自动改写论文结论。标识冲突不挂接其他文章的文字。
- **私有记录**：Agent流的tools分支另存实际工具返回及tool_call_id，不把工具正文追加进页面用的agent_messages/reasoning_trace。来源快照保留关系与source_engine，增加source_material_views，记录可用材料和模型片段的长度、SHA与范围。实际片段正文仍可从已有writer_sources等快照核查；新事件在选材前生成，最终是否入选以writer_sources为准。子研究内部完整工具轨迹不因此自动具备。

普通论文仍保留完整摘要、额外文字按原有约6000字符选片段；来源上下文20万字符与原有分批选材不变。通知文字计入同一材料预算，材料量变化可能影响原有选材批次数量；没有新增核查/写作模型阶段。PubMed自动全文默认仍关闭。
