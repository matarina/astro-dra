## 如何理解记录

- 当前说明描述现在；日期记录描述当时。部署、合并和质量验收是不同状态。
- 同名 `.md` 通常是说明，`.json` 是对应的结构化结果；没有同名文件时，完整目录会给出归属。带 `final`、`accepted` 或 `checks_passed` 的文件名/字段不能单独证明当前功能验收完成。
- 截图证明当时页面展示；截获请求或模拟报告不等于真实研究验证。失败、撤回、未部署和语义未决均保留。
- [旧严格核验计划](ldr-verification-engineering-plan.md)、`claim-evidence-step*` 和早期publication试验用于追溯，不恢复强制删句或阻断报告。
- `local-deep-research/` 的文档属于上游快照；旧 `ldr-monitor/` 和 `LLM-MODELS.md` 不描述当前实例。仓库外私有实验、日志和备份只登记位置，不复制到公共文档。

## 后续维护

功能有变化时更新当前状态与待办；每次会话简要更新开发接续；详细实现、部署、诊断或试验使用带日期的独立记录，并在完整目录登记其用途。保留原始结果，不用新成功覆盖旧失败。当前说明不再反复插入多段互相冲突的“最新”。
