# 通用证据连续性与最终稿核对（2026-10-27）

> 文档定位：工程已集成main；不代表语义全部通过。本页记录当时过程；当前状态见[状态总览](current-status.md)，有效后续见[待办](roadmap.md)。

本轮针对材料丢失、版本关系流转及写后新增错配改动共用流程。生产代码没有空间转录组平台、疾病名称、论文标识或样本数字专用分支。模型保持原接口 deepseek-v4-flash。部署与最终验证结果以配套JSON为准。

## 实现

1. Agent收尾恢复草稿/当前问题引用但未出现在本次搜索集合中的已注册来源。进入写作前，先为草稿所引来源预留完整摘要及已有正文相关片段，再选择可选来源；来源超过文本预算时按草稿章节/段落分批写作，机械拼接，不再通过一次总改写重新分配证据。单一不可分单位超限时保留草稿并记录 evidence_budget_unavailable，不能冒充成功核查。
2. PubMed/Europe PMC给出的显式 update_in / published_in 关系触发有限补取。正式记录具有自己的编号、DOI和摘要；原预印本记录/文本不覆盖。失败保留原版本和失败状态；不靠标题相似猜测正式版本，也不把查到新DOI当作证明两个版本的所有结论相同。对明确关联版本的引用，程序提出仅替换引用的候选（含两个版本共引的情况），仍需根据正式文本独立确认；不是盲目换号。
3. 原生一致性检查入口移到实际writer输出之后。按具体论断和引用材料组成小组，带入真实章节/表格上下文；论断编号由程序分配，模型无需重抄原句。每组要求按研究对象、数据/平台、方法、数量单位及结论分项比较，再返回各论断的判断；分项明确矛盾不能被总判断“支持”抹去，漏回条目标记未核查。整轮有限模型调用，耗尽后明确记录未核查部分。
4. 区分明确矛盾、证据范围问题、版本更新、证据不足。仅对唯一定位的小段提出修改，引用的原文须确实存在于当次提供的来源正文；省略/拼接而未定位的引文不进入独立确认，只有同次反馈中确实定位的原文可使用；另一次模型调用分别判断原句、改句、分析背景和章节归属。正确原句、不同分析、伪造引文、未知来源、无意义的当前/父章节搬移、原句后追加所谓纠正均不能直接落地。不整体重写报告，也不删除整篇或恢复发布门槛。
5. 证据不足时优先复用已取得正文，再按指定论文取Europe PMC开放正文；另一个技术文档走SearXNG/明确原始文档URL。每次下载限制超时、字节数和总次数/网络耗时，失败论文不对每个论断重复下载。自动全文开关仍关；这是写后争议的局部补证。网络失败或没有开放全文时保留未解决状态，不把摘要没写解释为论文没做。
6. HTML/JATS表格保留行、列和跨行/列标签，保留已有上下标/文内引用处理，排除script/style。既有保存的压平文本不会被自动还原；重新下载的文本才受新解析器处理。
7. 私有trace新增证据计划、写作后快照、逐组核对请求/响应、补证事件、候选修订独立确认、落地/未解决问题及最终正文。核对开启时缓冲writer输出，回调收到最终文本，避免显示与保存两稿不一致。详细过程继续只在 /data/research_traces 保存，不插入页面核验表。

开发回放曾发现检查模型误判正确句、把同一论文不同流程参数互换、无意义章节搬移及引入错误产品描述。这些失败促成了独立原句/改句判断、局部原文定位及章节检查，失败记录未删除；早期镜像未部署。单纯引文原文存在仍不能证明其支持整个论断，最终仍依赖模型的语义判断，可能漏检或误判。

当前网络实测出现10x官方页面HTTP429、SearXNG无可用正文、Europe PMC间歇SSL错误；保留事件，未关闭TLS校验，也不把搜索结果当已取得全文。不能声称已全面解决产品定义、平台归属、研究对象、期刊影响因子和样本单位问题。该流程会增加收尾时间，尤其是长报告和需要补证时；次数有上限但不是原来的两次模型调用。

保存前逐引用审计仍关闭；来源预算500、三源检索、原接口模型、全局PubMed自动全文默认关闭保持。部署仅针对5002应用，不变更5000/SearXNG/relay及原数据卷。Git远程认证仍不可用，无提交/推送/分支合并。

## 本轮实测结果

完整保存材料回放（最终分项检查流程、最后两项局部修复前）覆盖218原始来源：65个必要来源全部进入writer，重新写作86个来源、冻结旧稿85个来源；正式版本PMID41361894作为新来源219取得。重新写作407.166秒/29次真实调用，冻结旧稿348.293秒/30次真实调用，两者均明确review_incomplete，没有伪装成全部核查通过。重新写作没有出现“原始材料未提供、仅据草稿”的警示，但没有纳入117/195，不能据此宣称这两篇归属已全面修复。

最终镜像补充了可定位引文选择和明确版本的候选比较，随后对上述实际检查反馈作全组下游回放，重新调用独立确认。冻结稿2次真实确认，落地RCC研究对象纠正和ctSVG正式版引用；它是保存反馈回放，不是重跑全研究。最终镜像还做了实际handler→核对→确认→publication聚焦验证：2次真实调用，ctSVG引用更新通过，但RCC错配被确认模型漏过，保留未解决状态。由此证明自动修正仍不稳定，不能用一处成功回放作为已解决疾病归属的结论。

最早几版的误改、后续漏检、网络错误和全部过程都保留在私有实验目录；早期镜像均未部署。最终代码不包含本节论文/疾病/平台的专用判断。

正常写作稿的最终反馈回放进行了1次真实独立确认，候选版本替换未获确认，正文保持；因此两版本共引仍可能存在。该结果不标记为通过。
