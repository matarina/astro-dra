## 实现

- `overlay/ui/astro-locale-zh.js` 集中存放内置界面中文文案，覆盖模板、动态提示、设置名称与说明。词典来自应用自带文案，构建时批量翻译并修订常用术语/安全提示、校验占位符，浏览器不调用翻译模型，也不向翻译服务发送用户输入或论文材料。
- `overlay/ui/astro-i18n.js` 仅对已知界面词条进行显示层转换，处理文字、占位提示、工具提示、无障碍标签、原生确认框及固定图表标签。动态插入的控件也会处理；数值占位符和普通文本分开，分页不会误读“数据库页大小”，未知标识不会命中对象原型属性。
- 保护报告正文/目录、对话消息、论文/搜索结果、笔记、研究问题、历史标题、合集名称/说明、模型选项和原始日志。输入值、选项value、data标识、链接、API负载及已保存研究内容不经翻译；自定义名称保持原文。部分内置合集名称/说明本身是已保存资料记录，也沿用原文。
- 5个原生前端脚本只做必要的界面适配：日志筛选从按钮文字判断改用data-filter-type；中文设置搜索同时匹配中文显示名及原名；进度页兼容中文通用状态；新建对话的默认标题中文化。研究策略、检索/证据、模型调用、引用处理等Python代码不改。
- 公共布局、独立认证页及设置/对话页接入词典并更新资源入口。保留浅色/深色/跟随系统三项；修复设置页中文标题挤成竖排的布局，统一面包屑文字。

词典和本地化模块是前端资源，不是研究阶段的规则或模型提示词。原始日志、底层返回的未收录错误及配置/模型/数据名称仍可能保留英文，便于定位问题；后续上游新增界面文案需补充词典，不能把运行时转换当作自动翻译所有内容。
