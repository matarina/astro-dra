# 引用内容对应优化：材料传递与生成

日期：2026-10-19。范围：主开发仓库、5002对应安装版本的本地补丁；未部署运行服务。

## 判断依据

用户反馈少量正文与被引文献内容不对应，尚未提供具体报告原句。不能据此断定所有错例的根因。本轮根据实际代码修复可复现的问题，优先材料传递和生成，保留2026-10-16的辅助核查、不自动删改报告方向。

| 环节 | 确认的现象 | 本轮处理 |
|---|---|---|
| fetch工具 | 模型收到完整读取结果/聚焦摘要，但登记到来源池的文本只有约200字符 | 独立保存实际获取的fetched_content，最终写作读取原文，不以模型摘要替代原文；不把未知完整性的页面标成论文全文 |
| 来源复用 | add_results去重后不再向本轮Agent返回重复命中；跨章节reset后，旧来源也可能不在最终写作材料中 | 复用原编号，同时返回本轮实际命中；最终综合补回初稿/任务明确引用的已登记来源，不灌入整份历史书目 |
| PubMed解析 | 第一段被重复拼接；AbstractText.text丢失内嵌XML标签及后续文字 | 每段只读一次，用itertext保留基因名、否定词等完整文本 |
| 最终材料 | 编号和正文之间缺统一的标题/URL/材料范围说明；full_content空值会遮住可用snippet | 明确来源身份与abstract/fulltext/snippet/page excerpt范围，空值退回可用内容，优先原始摘要 |
| 写作提示 | 初稿与来源混合使用，推断容易看起来是论文结果 | 研究主Agent、子Agent和最终写作共用证据说明；原始材料优先，初稿无独立证据地位，保留对象/条件/数值/否定/因果强度；新增解读单独成句，摘要缺失不能推断全文缺失 |
| 详细章节 | 章节任务要求独特见解和具体数据，容易驱动摘要外扩写；避重复要求可能省略研究条件 | 改成仅使用检索材料支持的细节，明确区分前瞻解读，并要求保留必要的人群和实验条件 |
| 长材料 | 直接拼接可能挤占模型上下文 | 每来源至多约6000字符，约80000原文字符在来源间分配；长材料按任务取最多3个原文窗口并声明选段，保留原始来源池文本 |
| 重编号 | 尚未发现把A文献编号映射成B文献的复现证据 | 保留现有映射，补“生成编号→正文引用→展示链接”回归；不以改编号替代语义支撑检查 |

普通/详细正文仍保留，辅助审计仍写metadata。未启用旧ClaimRevision循环、严格发布门槛或正文核验表。未扩大自动来源池或开启默认PMC全文获取。

## 限制与后续

提示和原文保留不能保证模型忠实使用所有证据；当前小样本仍有概括范围和作者结果/报告解读混合的风险。同模型自评不独立，也存在误报；词项窗口对中文问题/英文原文的跨语言召回仍有限。原始全文可得性和文献身份的跨网站合并仍需具体错例验证。

下一轮应收集真实错例的“原句、原引用编号、展示编号、paper_id、模型当时实际收到的文本”，先判断是链接错配、文本缺失、未提供细节扩写还是范围外推。细节确实需要全文时定向获取对应PMC/出版页面，保留取得范围；不要把整个摘要库统一扩写成详细研究结论。按来源是否支撑陈述、事实覆盖和推断标识分别评估，可参考[ALCE](https://aclanthology.org/2023.emnlp-main.398/)，不能只看链接有效或模型说supported。
