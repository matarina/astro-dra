## 实现与接入

新增 research_verify/revision.py，复用 CitationQc 的逐引用证据与六维语义核查。
- supported 原子结论保留；复合结论尝试拆分。带明确细胞/动物实验范围的证据不能生成遗漏相应范围的主张，即使模型判为 supported。
- partial 基于原引用中已定位的支持片段补范围或缩写；unsupported 删除；unverifiable 独立放在待核验区。
- 严格 JSON 与 Pydantic 校验限制候选形状、引用范围及数量；禁止引入新引用编号、重复引用、多行内容或再次合并已识别的复合结论。
- 每个修订候选重新核查；仅 supported 且保留必要范围的候选进入正文。未通过的子主张有父主张关联与删除/待核验审计。
- 组装后的正文再次整体核查，异常或判定回退则 withheld，不返回旧草稿作为事实正文。
- 返回最终正文哈希、逐项动作、修订次数、最终逐引用证据；traceability_checked 仅表示本阶段结论支撑，不等于四需求 strict_verified。

LangGraphAgentStrategy._finalize 在追加来源及核验表前调用修订；findings.content 使用修订后正文，current_knowledge / formatted_findings 另附待核验和审计小节。无可保留结论时显示明确提示。现有 citation_qc JSON 记录最终检查，完整修订审计通过 citation_revision 返回；统一持久化留给下一项。

默认预算：LDR_VERIFY_REPAIR_MAX_ROUNDS=2（0–3），LDR_VERIFY_REPAIR_MAX_PROPOSALS=4（1–8），LDR_VERIFY_REPAIR_MAX_REQUESTS=8（0–32）。总请求预算仅计重写调用；原始/候选/最终 QC 调用另外发生，尚无全流程 token/耗时预算。

补充核查提示：并列省略句必须逐字引用完整连续句或真实谓语片段；不得重构原文引句。程序依旧拒绝原文不存在的引句。
